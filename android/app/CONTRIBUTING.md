# Contribution Guidelines

Thank you for your interest in contributing to the project, it is very appreciated!

## AI Policy

- You may only use AI/LLMs in your PR as a way to assist you in writing the code (e.g. inline suggestions or code review). **Fully AI-generated/"vibe coded" PRs will be closed.**
- If you do use AI/LLMs, please disclose how it was used, and the tool that you used (Cursor, Claude Code, Copilot...).

## How to contribute

Contributions can be done over pull requests in this repository. Always PR to the `main` branch. If you'd like ideas on what to contribute, take a look at the [issue tracker](https://tickets.nin0.dev/view_all_bug_page.php)!

Before working on a large change, please ask in either the support server, or an issue, that way it can be discussed before you put time in it.
